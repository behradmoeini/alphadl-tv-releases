# AlphaDL TV — releases

Built artifacts for the private `alphadl-tv` project.

- `AlphaDL-TV.apk` — sideload this on the TV.
- `version.json` — the self-update manifest the app fetches on launch.
- `NamayeshKhanegi.apk`, `namayesh.json` — the separate app and its update manifest.
- `KhanehLauncher.apk`, `khaneh.json` — the TV home screen and its update manifest.
